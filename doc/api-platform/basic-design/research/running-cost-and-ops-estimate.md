### 1.3 読み方（要点）

- **機構のランニングは月 2,000 円前後**で、支配項は CloudWatch（メトリクス + ログ = 費用の 2/3）。Lambda・S3・Scheduler は事実上ゼロ
- **アプリ数比例で増えるのは RC-7（メトリクス）・RC-10（ログ）・RC-12/13（App アカウント側）**。30 アプリでも月 1 万円台
- **App アカウント側に発生する費用が 2 件ある**（RC-12/13）。課金按分の説明（03 章 BL 系）にこの 2 件を「監視のための共通負担」として明記が必要 → RC-Q-1
- probe の通信は CloudFront 経由の HTTPS 数千リクエスト/月でデータ転送費は誤差（<$0.1）。apigateway:GET などコントロールプレーン呼び出しは**非課金**（公式価格ページの課金対象一覧に含まれないことを確認済み）
