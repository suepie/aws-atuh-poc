**用語の意味**（10 §10.0.4）:

- **認証構成情報** = アプリが提供する `monitoring.yaml` + `openapi.yaml`（+ 任意 `deploy-info.json`）
- **認証構成情報連携バケット** = **App アカウント側**の S3（`auth-monitoring-artifacts-{accountId}`）。アプリが置き、中央が読む
- **認証構成情報配置バケット** = **共通基盤アカウント側**の S3 ×1（`registry/` 台帳 + `openapi/` spec コピー）
- 2 つのバケットは**別物**。混同しないこと

### 置換してはいけない語（英語のまま）

`DiscoveryReadRole` / `DiscoveryLambdaRole` / `CentralProbeRole` / `ArtifactUploadRole-{appId}` / `alert-router-lambda-role` / `auth-monitoring-artifacts-{accountId}` / `DiscoveryLastSuccess` / `DiscoveryAccountErrors` / `AuthCheckCritical` / 台帳属性 `artifactBucket`・`artifactPrefix`・`lastArtifactVersions` / コードサンプル名 `central-probe-lib`・`alert-router-lambda`・`app-registry-lambda` / **`App Registry`・`OpenAPI Registry`**（配置バケット内の構造名として存続）

> `alert-router-lambda`（ディレクトリ名・ロール名）は**そのまま**。日本語化するのは日本語の説明文中の「Alert Router」だけ。

### 置換の副作用チェック

置換後に以下が発生していないか確認する:

- `認証構成情報認証構成情報` / `認証構成情報連携バケット バケット` のような二重
- `alert-router-lambda` が `アラート検知 Lambda-lambda` 等に化けていないか
- 「アラート検知 Lambda Lambda」（#7 と #8 の二重適用）
