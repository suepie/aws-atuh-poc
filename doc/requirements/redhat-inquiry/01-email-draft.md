社内向けの共通認証基盤を Keycloak（RHBK）+ ROSA HCP で構築する前提で設計しており、

【構成の概要】

  お客様企業のログイン基盤とつなぎ、自社ログイン基盤の Keycloak（別クラスタ・
  別 AWS アカウント）が、自前の基盤を持たないお客様の利用者を預かります。

・拡張部品（SPI）を 3 JAR・4 機能で自作し、管理用 API は Lambda に置いています。

【当日ご相談したいこと】
1. 上記構成のレビュー（無理がある点・よくある失敗）

   （金融機関のお客様での事例もあれば）
3. 災害対策の構成例と、別リージョンでの再構築の実績時間
4. HCP 利用時に私たちの側に残る日常運用
5. 3 年契約の見積

【書面でいただければ足りるもの】
拡張部品の API 互換性、大阪リージョンのインスタンス在庫、

お忙しいところ恐縮ですが、よろしくお願いいたします。

## 送付時の注意

- **添付する一覧は `質問（先方提示用）` と `補足（先方提示用）` の 2 列のみ**にする。
  `なぜ聞くか` `回答が無いとどうなるか` には「残ブロッカー」「顧客監査に応えられない」など
  **社内の事情がそのまま入っている**ため、必ず非表示にする。
- **「差し支えない範囲で」を事例系の質問（G-03 / G-04 / G-05）に必ず添える。**
  他社事例は守秘の関係で答えられないことがあり、答えやすくしておく。
- 短縮版 A の 5 点は **G 群（事例・構成レビュー）とほぼ一致**させている。
  仕様の確認は書面に回し、**会話でしか取れないものを面談に集中**させる意図。
